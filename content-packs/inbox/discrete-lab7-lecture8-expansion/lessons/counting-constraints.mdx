## Что это?
Сложные подсчёты включают «хотя бы один», запрет соседства, различные классы участников, маршруты и дополнительные условия. Вместо угадывания формулы важно разбить множество исходов на независимые непересекающиеся случаи или применить Inclusion–Exclusion.

## Интуиция
Для «хотя бы один» часто проще вычесть варианты без нужного признака. Для запрета соседства можно сначала расположить все прочие объекты, а затем вставить запрещённые объекты в промежутки. Для кратчайших решётчатых путей порядок шагов определяет маршрут.

## Формула и её смысл
$$|A\cup B|=|A|+|B|-|A\cap B|.$$
Для неотрицательных целых решений $x_1+\cdots+x_k=n$ метод Stars and Bars даёт $\binom{n+k-1}{k-1}$. Для кратчайшего пути из $r$ горизонтальных и $u$ вертикальных шагов число маршрутов $\binom{r+u}{r}$.

## Разберём на примере
Для 3 женщин и 4 мужчин комитет из 4, где женщин больше мужчин и есть хотя бы один мужчина, возможен лишь состав 3+1: $\binom33\binom41=4$.

## Частая ошибка
Смешивать случаи с пересечениями; забывать, что «больше» — строгое неравенство. При кратчайших путях разрешены только шаги, которые приближают к цели.

## Экзаменационный ориентир
Запиши все допустимые целочисленные составы, затем для каждого случая вычисли число выборов.
