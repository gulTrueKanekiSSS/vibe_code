## Что это?

Фраза «для любого ε>0» означает, что утверждение работает для каждого положительного допуска, насколько бы маленьким он ни был. Нельзя выбрать только удобное ε.

## Английские термины

Epsilon terminology — Язык эпсилон

## Формула и её смысл

$$
|x-a|<\varepsilon\iff a-\varepsilon<x<a+\varepsilon
$$

a — центр, ε > 0 — допустимое отклонение.

## Разберём на примере

|x−3|<0.1 означает 2.9<x<3.1.

## Частая ошибка

ε — не «самое маленькое положительное число»: такого действительного числа нет.

## Как говорит преподаватель

For every epsilon greater than zero… → Для любого положительного допуска ε…

## Проверь понимание

Какова верхняя граница x из |x−3|<0.1?
