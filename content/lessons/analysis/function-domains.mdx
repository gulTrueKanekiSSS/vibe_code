## Что это?

Функция $f:A\to B$ каждому элементу области определения $A$ ставит в соответствие ровно один элемент множества $B$. Формулы недостаточно: выбор $A$ и $B$ влияет на инъективность, сюръективность и существование обратной функции.

## Интуиция

Представь стрелки из $A$ в $B$. Инъекция запрещает двум разным входам попадать в одну точку. Сюръекция требует, чтобы каждая точка $B$ получила стрелку. Бие́кция выполняет оба требования.

## Formal Definition

$f$ инъективна, если $f(x)=f(y)$ влечёт $x=y$. Она сюръективна, если для каждого $b\in B$ существует $a\in A$ с $f(a)=b$. Образ $f(A)$ может быть меньше codomain $B$. Прообраз множества $S$ — все $x\in A$, для которых $f(x)\in S$; он существует и без обратной функции.

## Английские термины

Domain — область определения; codomain — целевое множество; range / image — образ; preimage — прообраз; inverse function — обратная функция; restriction — сужение.

## Формула и её смысл

$$
f^{-1}(S)=\{x\in A:f(x)\in S\}
$$

Это прообраз множества, а не деление на $f$. Для обратной функции нужно дополнительно установить биективность.

## Почему формула работает?

Прообраз ищет допустимые входы по условию на выход. Решение неравенства $f(x)\in S$ обязательно пересекается с исходной областью определения $A$.

## Разберём на примере

Для $\sqrt{x-1}/(x-3)$ требуются одновременно $x\ge1$ и $x\ne3$. Область — $[1,3)\cup(3,\infty)$. Квадратный корень допускает нулевой аргумент, знаменатель — нет.

## Пример уровня университета

Функция $f(x)=x^2$ из $\mathbb R$ в $[0,\infty)$ сюръективна, но не инъективна: $f(1)=f(-1)$. Сужение входов до $[0,\infty)$ даёт биекцию и обратную $\sqrt y$. Сужение до $(-\infty,0]$ тоже даёт биекцию, но обратная равна $-\sqrt y$. Обе ветви верны для разных областей.

## Пример-ловушка

У $f(x)=(x^2-1)/(x-1)$ выражение сокращается до $x+1$ только при $x\ne1$. Исходная функция не получает значение в дырке после алгебраического упрощения.

## Частая ошибка

Для $\ln g(x)$ нужно строго $g(x)>0$, а для $\sqrt{g(x)}$ — $g(x)\ge0$. У $\sqrt{\ln x}$ дополнительно $\ln x\ge0$, поэтому итог $x\ge1$.

## Зачем это нужно?

Проверка ограничений предотвращает посторонние решения. Обратная функция нужна, когда по результату требуется однозначно восстановить вход.

## Связи с другими темами

Утверждения о стрелках можно записать [кванторами](/topics/quantifiers). Для графика $f(x-a)+b$ горизонтальный сдвиг равен $a$, вертикальный — $b$; знак внутри скобок легко перепутать.

## Как говорит преподаватель

“Choose domain and codomain restrictions to make the function bijective.” Укажи оба множества и докажи оба свойства.

## Краткий итог

Сначала область определения, затем образ; только после этого свойства отображения и обратная функция. Прообраз множества не требует инъективности.

## Проверь понимание

Выбери ограничение для квадрата и запиши обратную функцию.
