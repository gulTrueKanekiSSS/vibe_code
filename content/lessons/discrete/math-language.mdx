## Что это?

Let означает «пусть», assume — «предположим», hence — «следовательно». If and only if означает равносильность: нужно доказать оба направления.

## Английские термины

Mathematical language — Математический английский

iff — тогда и только тогда; hence — следовательно

## Разберём на примере

Let n be an integer. → Пусть n — целое число.

## Частая ошибка

If и if and only if требуют разного объёма доказательства.

## Проверь понимание

Сколько направлений нужно доказать для if and only if?
