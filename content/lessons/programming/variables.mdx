## Что это?

Переменная в C — именованный объект с типом. Тип определяет допустимые значения и операции. Локальную переменную нужно инициализировать перед чтением.

## Английские термины

Variables — Переменные

## Разберём на примере

```c
int count = 3;
count = count + 2; // теперь 5
```

## Частая ошибка

Чтение неинициализированного автоматического int может приводить к неопределённому поведению.

## Проверь понимание

int x=4; x=x+3; Каково значение x?
