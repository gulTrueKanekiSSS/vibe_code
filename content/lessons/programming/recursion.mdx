## Что это?

Рекурсивная функция вызывает себя на меньшей задаче. Для правильного решения нужны база, правило уменьшения и действие после возврата. Одного наличия return недостаточно: исполнение должно достичь базы для каждого допустимого входа.

## Интуиция

Вызов может отложить работу: «сначала вычисли меньшую сумму, потом добавь мой n». Пока младший вызов не завершится, старший хранит своё состояние. Полезно рисовать таблицу входов и возвращаемых результатов.

## Formal Definition

Для sum(n), n≥0, определим базу sum(0)=0 и шаг sum(n)=n+sum(n−1). Каждый переход уменьшает неотрицательное целое n, поэтому число переходов конечно. В C для больших входов дополнительно учитываются переполнение и ресурсы исполнения.

## Английские термины

Base case — базовый случай; recursive case — рекурсивный случай; call frame — состояние вызова; return value — возвращаемое значение; automatic / static storage duration — автоматическое / статическое время хранения.

## Правило и его смысл

Автоматическая локальная переменная создаётся заново для каждого входа в блок. Статическая локальная переменная существует всё время работы программы: её значение сохраняется между рекурсивными и обычными повторными вызовами.

## Почему это работает?

Каждый вызов получает своё значение параметра. Изменение n в младшем вызове не меняет параметр старшего. Статическая переменная, напротив, обозначает один и тот же объект во всех вызовах функции.

## Разберём на примере

Для небольшого неотрицательного n:

~~~c
int sum(int n) {
    if (n == 0) return 0;
    return n + sum(n - 1);
}
~~~

sum(3) ждёт sum(2), тот — sum(1), затем sum(0). Возвраты: 0, 1, 3, 6. Нельзя складывать только значения параметров в базе: вклад остальных вызовов выполняется после возврата.

## Пример уровня университета

~~~c
int visit(int n) {
    static int calls = 0;
    ++calls;
    if (n == 0) return calls;
    return visit(n - 1);
}
~~~

В свежем процессе visit(2) увеличивает один счётчик трижды и возвращает 3. Следующий отдельный вызов visit(1) увеличивает его ещё дважды и возвращает 5. Объявление static не сбрасывает значение при каждом входе.

## Пример-ловушка

~~~c
int bad(int n) {
    if (n == 0) return 0;
    return bad(n++);
}
~~~

В младший вызов передаётся прежнее значение n. Положительный вход не приближается к базе. Нельзя объявлять конкретный результат при исчерпании ресурсов: программа не вычисляет обещанную величину.

## Частая ошибка

Вывод до вызова и после вызова происходит в разном порядке. Также выражение с несколькими вызовами, меняющими общее состояние, может зависеть от неуказанного порядка вычисления операндов. В учебных трассировках разделяй такие вызовы отдельными инструкциями.

## Зачем это нужно?

Рекурсия естественна для обработки цифр, факториала и вложенных структур задачи. Для суммы цифр неотрицательного числа полезны n%10 и n/10; база должна корректно обработать ноль.
