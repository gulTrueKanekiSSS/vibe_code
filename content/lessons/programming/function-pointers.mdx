## Что это?

Указатель на функцию позволяет выбрать вызываемую функцию во время работы программы. Его тип должен соответствовать сигнатуре функции.

## Английские термины

Function pointers — Указатели на функции

## Разберём на примере

```c
int square(int x) { return x*x; }
int (*f)(int) = square;
// f(3) равно 9
```

## Частая ошибка

int (*f)(int) — указатель на функцию; int *f(int) — функция, возвращающая указатель.

## Проверь понимание

Функция square(x) возвращает x*x. Чему равно square(4)?
