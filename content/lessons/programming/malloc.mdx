## Что это?

malloc выделяет запрошенное число байт или возвращает NULL. Проверяй результат; после использования вызови free ровно один раз.

## Английские термины

Dynamic memory — Динамическая память

## Разберём на примере

```c
int *p = malloc(3 * sizeof *p);
if (p != NULL) {
  p[0] = 7;
  free(p);
}
```

## Частая ошибка

malloc не инициализирует память. После free обращаться к ней нельзя.
