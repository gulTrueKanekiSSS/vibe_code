## Что это?

Указатель хранит адрес объекта или специальное нулевое значение. Оператор `&x` получает адрес `x`, а `*p` обращается к объекту, на который указывает `p`. Через указатель можно изменить исходный объект.

## Интуиция

`x` — сама ячейка с данными, `&x` — её адрес, `p` — переменная с этим адресом, `*p` — содержимое найденной ячейки. Указатель не хранит отдельную копию `x`.

## Formal Definition

В C объектный указатель типа `T *` может указывать на объект типа `T` (с учётом правил совместимости типов) или иметь нулевое значение. Разыменование допустимо только для указателя на существующий доступный объект; разыменование `NULL`, висячего или неинициализированного указателя приводит к неопределённому поведению.

## Зачем это нужно?

Указатели позволяют передавать адрес объекта функции, работать с массивами и динамической памятью. Их тип сообщает компилятору, как интерпретировать объект по адресу.

## Английские термины

Pointers — Указатели

pointer — указатель; address-of operator `&` — получение адреса; dereference operator `*` — разыменование; dangling pointer — висячий указатель; null pointer — нулевой указатель.

## Правило и его смысл

Для `int x; int *p=&x;` выражение `p` имеет тип `int *`, а `*p` — lvalue типа `int`, обозначающее тот же объект, что `x`. В объявлении `int *p` звёздочка задаёт тип; в выражении `*p` она разыменовывает адрес.

## Почему это работает?

Присваивание `p=&x` записывает адрес `x` в `p`. Затем `*p=20` находит объект по этому адресу и меняет его. Так как `x` и `*p` обозначают одну ячейку, чтение `x` вернёт новое значение.

## Разберём на примере

```c
int x = 10;
int *p = &x;
*p = 20; // изменили x
```

После присваивания `x` равен `20`, а `p` по-прежнему хранит адрес `x`.

## Пример уровня университета

```c
int a = 4;
int b = 7;
int *p = &a;
*p += 3;  // a == 7
p = &b;   // p теперь указывает на b
*p += 2;  // b == 9, a остаётся 7
```

Прослеживай отдельно адрес в `p` и значение объекта по этому адресу. Смена `p` не копирует и не меняет старый объект.

## Пример-ловушка

```c
int x = 5;
int *p = &x;
int *q = p;
*q = 8;  // x == 8 и *p == 8
```

Копирование указателя не создаёт копию `x`: `p` и `q` указывают на один объект. Это называется aliasing.

## Частая ошибка

Нельзя разыменовывать `NULL`, освобождённый или неинициализированный указатель. Не путай `p=&x` (сохранить адрес) с `*p=x` (записать значение по уже корректному адресу).
