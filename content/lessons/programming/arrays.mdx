## Что это?

Массив хранит подряд элементы одного типа. Индексы начинаются с нуля: у массива из n элементов последний индекс n−1.

## Английские термины

Arrays — Массивы

## Разберём на примере

```c
int a[3] = {10, 20, 30};
// a[1] равно 20
```

## Частая ошибка

C не проверяет границы массива автоматически.

## Проверь понимание

int a[]={4,8,12}; Чему равно a[2]?
